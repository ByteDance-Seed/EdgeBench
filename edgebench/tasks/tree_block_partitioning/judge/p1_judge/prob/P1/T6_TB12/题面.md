## 题目描述

这是一道交互题，下发文件包含样例和交互库，下发的交互库和实际测试的交互库不同。

你需要包含头文件 `data.h` ，本地测试时，需要把你的程序和下发的交互库文件一起编译，输入输出已经由交互库处理，你只需要实现指定的函数 `solve`。

你可以调用以下函数：

```cpp
void Data::add_eq(const Data &a);
void Data::add(const Data &a,const Data &b);
void Data::clr();
void Operation::apply(Data &w)const;
void Operation::apply(Operation &w)const;
void Operation::clr();
```

定义两种二元运算 $+,*$ 如下：

对任意 `Data` 类型的元素 $a,b,c$ ，

`a.add_eq(b)` 将 $a$ 修改为 $a+b$ ；

`a.add(b,c)` 将 $a$ 修改为 $b+c$ ；

`a.clr()` 将 $a$ 修改为 $e_+$ ，$e_+$ 是一个 `Data` 类型的常量；

$e_++a=a+e_+=a$

$a+b=b+a$

$(a+b)+c=a+(b+c)$

对于任意 `Operation` 类型的元素 $f,g,h$ ，任意 `Data` 类型的元素 $a,b$ ，

`f.apply(a)` 将 $a$ 修改为 $f*a$ ；

`f.apply(g)` 将 $g$ 修改为 $f*g$ ；

`f.clr()` 将 $f$ 修改为 $e_*$ ，$e_*$ 是一个 `Operation` 类型的常量；

$(f*g)*h=f*(g*h)$

$(f*g)*a=f*(g*a)$

$f*(a+b)=(f*a)+(f*b)$

$e_**f=f*e_*=f$

$e_**a=a$ 

另外，类型 `Data` 和 `Operation` 的构造函数、析构函数、赋值运算也是允许调用的。

你需要实现一个函数：

```cpp
void solve(
	int n,
	int m,
	int fa[],
	Data d0[],
	int x[],
	int y[],
	Operation o[][2],
	Data ans[][2]);
```

给定一棵 $n$ 个结点（编号为 $1,2,\dots,n$）的有根树；

对 $2\le i\le n$ ，`fa[i]` 是编号为 $i$ 的结点的父亲的编号（保证比 $i$ 小）；

每个结点上有了状态信息，编号为 $i$ 的结点的状态信息初始为 `d0[i]` 。

你需要执行 $m$ 次操作（编号为 $0,1,\dots,m-1$ ），操作按编号升序依次进行。

编号 $i$ 的操作由 `x[i],y[i],o[i][0],o[i][1]` 描述，你需要将答案保存到 `ans[i][0],ans[i][1]` 中；

具体地，你需要将树上的结点分为两类，第一类结点与编号 `x[i]` 的结点的距离（边权为1）不超过 `y[i]` ，第二类结点是不属于第一类结点的结点；

对每个第一类结点，设其编号为 $j$，你需要依次执行 `ans[i][0].add_eq(d0[j])` 和 `o[i][0].apply(d0[j])`；

对每个第二类结点，设其编号为 $j$，你需要依次执行 `ans[i][1].add_eq(d0[j])` 和 `o[i][1].apply(d0[j])`；

你也可以用其它操作代替要求执行的操作，但需要保证在 `solve` 函数执行完后， `ans[i][0]` 和 `ans[i][1]` 的值和上述操作得到的值相等。

你需要保证操作的总代价不超过题目的限制，具体地：计算 $a+b$ 或 $a*b$ 时，如果 $a,b$ 都不是 $e_+$ ，也都不是 $e_*$ ，则代价为 1，否则代价为 0；总代价是每次计算 $a+b,\;a*b$ 的代价之和。



## 数据范围

对 $20\%$ 的数据，满足 $n,m\le 10^3$。

对另外 $20\%$ 的数据，满足 $fa[i] = i-1$。

对另外 $20\%$ 的数据，满足 $fa[i] = i/2$ (向下取整)。

对另外 $20\%$ 的数据，满足 $n,m\le 3\times 10^4$。

对于所有数据， 满足 $1\le n,m\le 10^5$ ，对 $2\le i\le n$ 有 $1\le fa[i]\le i-1$，对 $0\le i\le m-1$ 有 $0\le y[i]\le n-1$，总代价限制 $1.5\times 10^8$。

时间限制：12s

空间限制：512MB
