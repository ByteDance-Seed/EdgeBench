You need to complete six problems, with a total score of 100 points. The scores for these six problems are 5, 5, 10, 15, 25, and 40 points respectively. Each problem has several sets of test data; if all test data for a problem is passed, you receive the full score for that problem; if not all test data is passed but some subtasks/test cases are passed, each passed subtask/test case earns only half of its original score. Please work on the problems in order, with the goal of solving each one. These problems are progressive in difficulty — if you cannot solve a particular problem, it is recommended to review the solutions to previous problems for insights.
When submitting code, the code files for the six problems should be named T1.cpp T2.cpp T3.cpp T4.cpp T5.cpp T6.cpp.
