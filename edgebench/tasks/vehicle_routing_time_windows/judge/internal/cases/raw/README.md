```bash
# Step 1: Fetch 56 Solomon-100 original files from GitHub public mirror
cd raw_solomon100/
for name in C101 C102 ... RC208; do  # 56 names; see fetch_solomon.sh
```

merging the above two steps, and also writes `.bks` files.

## Remote Evaluation Deployment

The evaluation side typically does one more step of **node ID scrambling** (to prevent hardcoded answers),
using `scramble_nodes.py` to convert `raw/` into `scrambled/`, then mount to the evaluator:

```bash
python3 scramble_nodes.py --src raw/ --dst scrambled/ --map scramble_map.json --seed 20260507
docker run -d -p 8080:8080 \
    -v "$PWD/scrambled":/srv/cvrptw/cases:ro \
    ...
```

After deployment, the evaluator reads `.txt` from the mounted volume and computes `EUC_2D_X10`
distances for scoring.

## Data Compliance

The Solomon-100 dataset has been a public academic benchmark since Solomon (1987);
most OR textbooks and papers cite it directly, with no copyright issues. The copies
hosted in the `iRB-Lab/py-ga-VRPTW` GitHub repository are consistent with the
SINTEF official VRPTW page (https://www.sintef.no/projectweb/top/vrptw/).
